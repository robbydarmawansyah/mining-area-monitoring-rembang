# Results and Discussion

## 1. Land-Cover Classification

A Random Forest model was used to classify the study area into five land-cover categories:

- Vegetation
- Agriculture
- Bare / Open Land
- Built-up
- Water

The classification workflow successfully generated annual land-cover maps for 2018–2025.

## 2. Model Validation

The polygon-based validation produced the following results:

- Overall Accuracy: approximately 97.45%
- Kappa Coefficient: approximately 0.963

These values represent validation against interpreted sample polygons and should not be considered independent ground-truth accuracy.

## 3. Annual Land-Cover Analysis

Annual classification outputs were generated to examine land-cover patterns and changes between 2018 and 2025.

The analysis highlights changes in vegetation, agricultural land, bare/open land, built-up areas, and water.

## 4. Potential Quarry Candidate Screening

Potential bare/open-land candidates were identified by combining Random Forest and Dynamic World results.

The screening process generated 13 candidate polygons within the pilot reference study area, with a combined area of approximately 68.07 hectares.

These polygons are preliminary screening results, not confirmed mining boundaries or official mining concession areas.

## 5. Interactive Dashboard

The Google Earth Engine application allows users to:

- Explore annual land-cover maps.
- Select different monitoring years.
- Inspect potential candidate areas.
- View supporting statistics and map layers.

## 6. Key Findings and Limitations

The workflow demonstrates how satellite imagery and cloud-based geospatial processing can support preliminary land-cover monitoring.

However, bare/open land may include agricultural fields, exposed soil, construction areas, and other non-mining surfaces. Further verification using high-resolution imagery, mining records, and field observations is necessary.
